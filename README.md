# ✨ Shiny Hunt Counter

O teu companheiro para shiny hunting. Conta os encontros, ovos ou resets enquanto jogas, mostra as tuas probabilidades e guarda o histórico de todos os shinies que apanhaste.

## O que podes fazer

- Criar hunts para qualquer Pokémon, em qualquer jogo, com o método que preferires.
- Contar com um clique ou com uma tecla (F8 por defeito), mesmo com o jogo aberto à frente.
- Ver as tuas probabilidades, o tempo de jogo e as estatísticas de cada sessão.
- Manter um contador pequeno sempre visível por cima do jogo.
- Guardar cada shiny no teu histórico, com data e screenshot.

## Como instalar

1. Clica em **Releases**, do lado direito desta página.
2. Descarrega um destes ficheiros:
   - **ShinyHuntCounter-portable.exe** para abrir logo, sem instalar.
   - **Shiny Hunt Counter setup.exe** para instalar e ter um atalho no menu Iniciar.
3. Na primeira vez, o Windows pode mostrar a mensagem "O Windows protegeu o seu PC". Clica em **Mais informações** e depois em **Executar mesmo assim**. Isto só acontece na primeira vez.

Funciona em Windows 10 e 11.

## Imagens dos Pokémon

A app vem sem imagens. Se tiveres as tuas, vai a **Settings → Artwork** e escolhe a pasta ou o ficheiro .zip onde as guardaste.

- Dá a cada imagem o número ou o nome do Pokémon, por exemplo `025.png` ou `pikachu.png`.
- Põe as versões shiny numa pasta chamada `shiny`.

## Guardar os teus hunts

O progresso é guardado automaticamente no teu PC. Para teres uma cópia de segurança, ou para passares os teus hunts para outro computador, usa **Settings → Data → Export**.
